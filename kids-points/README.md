# כוכבים בבית

אפליקציית נקודות להורים: כוכבים על מעשים טובים, סימנים על התנהגות לא בסדר, חנות פרסים וסולם תוצאות לסוף היום.

- קובץ אחד: `index.html`. פותחים בדפדפן (גם בטלפון), אין התקנה.
- הנתונים נשמרים במכשיר (localStorage). בהגדרות יש גיבוי/שחזור להעברה בין מכשירים.
- כשהקובץ מפורסם כ-Artifact ב-claude.ai עם יכולת `db`, הנתונים משותפים בזמן אמת בין כל מי שפותח אותו.
- העקרונות (כוכבים לא נלקחים, הפך חיובי, תוצאות קצרות ומיידיות, יחס חיובי) מוסברים בתוך האפליקציה בהגדרות.
